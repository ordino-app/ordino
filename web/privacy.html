The website

  • No cookies, no analytics, no tracking, no embedded third-party content. The fonts are hosted here, not loaded from Google.
  • The site is hosted on GitHub Pages. GitHub logs visitors' IP addresses for security and to keep the service running, as the provider of its own service. See the GitHub Privacy Statement.

The app

  • ordino works on your Mac only. It reads window positions and sizes through the macOS Accessibility permission to arrange them. It does not record your screen, read window contents, or send anything about your windows anywhere.
  • Your settings stay on your Mac.
  • Update check: ordino downloads a small file (appcast.xml) from GitHub Pages to see whether a new version exists, automatically about once a day; you can turn this off in Settings › Updates. Like any web request, this shows GitHub your IP address and the app's version. No system profile or identifier is sent. Legal basis: legitimate interest in delivering security and bug fixes (Art. 6(1)(f) GDPR).

Donations
